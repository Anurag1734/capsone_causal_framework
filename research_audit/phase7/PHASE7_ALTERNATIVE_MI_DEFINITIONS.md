# Phase 7C - Alternative MI Outcome-Code Definition

The roadmap specifies acute-MI-code-only versus a broad MI-code definition but does not enumerate the broader code list. This sensitivity operationalizes broad current-admission MI using the existing finalized audit field `mi_code_this_admission`: acute ICD-9 410*/ICD-10 I21*/I22* OR historical ICD-9 412/ICD-10 I25.2 on the same admission. This is the broadest current-admission definition supported by the accepted Phase 3 flags. Historical/prior-only nonacute admissions remain outside the Layer 2 case/control contrast; clean controls remain admissions without documented current or prior MI. This choice is documented rather than silently changing the primary acute definition.

The broad Layer 2 cohort has 181,643 admissions (21,930 broad current-MI cases; 159,713 clean controls), compared with 167,066 primary admissions (7,353 acute cases). Broad-definition prevalence in this comparison is 12.07%. 85/95 adjusted feature estimates retained the acute-only primary direction; 76/95 features passed BH FDR under the broad definition versus 67 physiological+technical primary significant features.

Layer 1 broad-outcome contrasts use the same selected-admission population and Phase 4 exposure-specific sets, redefining the current-admission outcome as acute OR historical code; prior MI stays descriptive. Full counts, estimates, patient intervals, and feature multiplicity results are in `PHASE7_ALTERNATIVE_MI_RESULTS.csv`. The broad definition mixes acute and old-MI diagnoses and is intentionally a coding sensitivity, not a new primary clinical estimand. It does not imply event timing.
