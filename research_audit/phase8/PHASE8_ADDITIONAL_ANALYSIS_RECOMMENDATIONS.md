# Phase 8 Additional Analysis Recommendations

No additional analyses were run. These proposals are separate from completed Phase 3–7 work and require approval before implementation. The current manuscript remains scoped to the existing primary and finalized sensitivity results.

| Proposal | Scientific problem and current gap | Data and assumptions needed | Proposed target / comparison | Publication need and scope |
|---|---|---|---|---|
| Layer 1 look-back sensitivity | Recorded chronic-condition history may be affected by how far back the EHR history is searched; existing saved estimates use finalized binary histories and do not quantify look-back dependence. | Encounter dates, diagnosis dates, a prespecified look-back window, reliable enrollment/observation time, and no differential capture after accounting for measured factors. | Re-estimate each Layer 1 adjusted risk difference among exposure histories documented in a fixed pre-admission window (e.g., 1 year versus the existing all-available history); retain same acute-MI outcome and covariate definitions where temporally coherent. | Optional robustness check. Could materially clarify exposure misclassification but risks selecting patients with longer observation. Adds analysis beyond Phase 7; it does not resolve causal timing or unmeasured confounding. |
| Layer 2 cardiac-only comparator | Clean controls may include noncardiac admissions with different care/ECG ordering pathways. The current analysis compares acute-MI-coded cases with clean controls, and measured selection weighting does not ensure comparable clinical context. | Validated diagnosis groups and admission codes for a prespecified cardiac comparator; sufficient feature coverage and overlap; clinically defensible exclusion of MI and consistent ECG selection. | Compare acute-MI-coded admissions with admissions having a prespecified non-MI cardiac diagnosis, using the same ECG feature outcomes and adjustment set, with a clearly stated admission-level adjusted mean difference. | Optional, potentially informative to specificity, but changes comparator and estimand. Not necessary to describe the current target; approval needed. Comparator diagnoses may themselves be ECG-defined, causing incorporation/selection issues. |
| Layer 2 ATT or overlap weighting | Existing AIPW reports a marginal contrast in the selected target population and has limited exposure overlap/clipping. A target focused on MI-coded cases or clinical equipoise could reduce extrapolation dependence. | Saved cross-fitted propensity scores or reproducible estimation inputs, adequate common support, explicit weight diagnostics, and a prespecified target population. | ATT: average adjusted feature difference for MI-coded admissions versus their estimated no-MI counterfactual among the treated-support population. Overlap weighting: contrast in the propensity-overlap population with weights proportional to e(1−e). | Optional, not a correction that establishes causality. Changes the target estimand and adds a new weighting sensitivity beyond Phase 7; it is not essential to interpret the current selected-cohort association if limits are clear. |
| Negative-control analysis | Could probe residual confounding or diagnostic processes if a credible negative-control exposure or outcome exists. Current work does not contain one. | Clinically justified variable known not to causally affect the target but sharing confounding/selection pathways; validated data and defensible exclusion restriction. | Prespecified negative-control contrast evaluated with the same cohort and adjustment approach. | Not recommended without a specific, defensible negative control. Choosing one post hoc risks misleading reassurance; would expand scope. |

## Recommendation

Do not run additional analyses solely to increase model count. The manuscript can proceed to final scientific review after text, metadata, and bibliography follow-up, with current analyses labeled accurately. If a reviewer requests an added analysis, prioritize a clinically justified comparator or look-back analysis only after verifying the required variables and defining the target. ATT/overlap weighting should be considered only if an alternative target population is scientifically desired. No proposal is necessary to fix a demonstrated numerical error, and none resolves unknown MI-onset-to-ECG order or diagnostic incorporation. Explicit user approval is required before any is run.
