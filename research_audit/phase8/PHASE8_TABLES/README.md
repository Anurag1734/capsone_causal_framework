# Manuscript tables

Tables 1–5 are the main-text cohort, Layer 1, Layer 2, feature-group omnibus, and feature-group sensitivity summaries. Tables S1–S6 contain selection-weighted, broad-code, subgroup, interaction, unmeasured-confounding, and primary/sensitivity comparisons. They are reformatted from finalized Phase 3–7 outputs; no estimates were refit here.

Layer 2 effect columns include the estimate in the original stored feature unit and its standardized form (stored-unit difference divided by the primary-cohort feature SD). Always state which scale is being reported. `QRS_Dur_Global_count` is a technical/support measure and should not be described as a physiological ECG outcome. BH discovery counts are over 95 feature tests unless explicitly separated as physiological-only.
